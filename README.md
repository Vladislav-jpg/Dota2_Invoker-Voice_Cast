# Dota2_Invoker-Voice_Cast

Минималистичный, быстрый и независимый от раскладки скрипт для применения способностей Инвокера в Dota 2 с помощью голоса. 

В отличие от тяжелых аналогов, эта версия работает полностью вслепую (без GSI/оверлеев) и мгновенно реагирует на фразы, перехватывая микрофон в реальном времени.

## 🚀 Особенности
- **Мгновенное срабатывание:** Словарь распознавания ограничен только нужными фразами, что снижает нагрузку на CPU до нуля и делает реакцию моментальной.
- **Никаких зажатий кнопок:** Микрофон слушается непрерывно. Просто скажи заклинание в любой момент драки.
- **Независимость от раскладки:** Используются аппаратные скан-коды кнопок. Скрипт сработает идеально, даже если у вас случайно включена русская раскладка (ЙЦУКЕН).
- **Офлайн распознавание:** Звук никуда не отправляется, используется локальная легковесная модель Vosk.

## 🛠️ Установка (Для пользователей .exe)

Если вы скачали готовый `.exe` файл, Python устанавливать **не нужно**:
1. Скачайте архив с релизом и распакуйте его в удобное место.
2. Скачайте русскую языковую модель [vosk-model-small-ru-0.22](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip).
3. Распакуйте архив с моделью и **переименуйте получившуюся папку в `model`**.
4. Положите папку `model` в ту же директорию, где находится ваш файл `voice_invoke.exe`.
5. Запустите `voice_invoke.exe` **от имени администратора** (это необходимо, чтобы скрипт мог нажимать кнопки в игре).

*Структура файлов должна выглядеть так:*
```text
/Ваша_Папка
  ├── voice_invoke.exe
  └── /model
      ├── am
      ├── conf
      ├── graph
      └── iv
```

## 🎮 Как использовать
Скрипт автоматически применяет заклинание после распознавания. Логика каста: **Сферы -> Invoke -> Слот 1**.
По умолчанию установлен режим **Quickcast** (Быстрое применение — только нажатие кнопки).

| Способность | Что говорить |
|---|---|
| Cold Snap | «колд», «холод», «заморозка» |
| Ghost Walk | «гост волк», «походка призрака» |
| Ice Wall | «айс вол», «стенка» |
| E.M.P. | «эмп», «и эм пи», «импульс» |
| Tornado | «торнадо», «ветра» |
| Alacrity | «ускорение» |
| Sun Strike | «сан страйк», «солнечный удар» |
| Forge Spirit | «духи» |
| Chaos Meteor | «котлета», «метеор», «хаос метеор» |
| Deafening Blast | «бласт» |
| Cataclysm | «катаклизм» *(нажимается автоматически через Alt)* |

## 💻 Для разработчиков (Запуск из исходников)

Требуется Python 3.9+
```bash
pip install vosk sounddevice keyboard mouse
```
*На Linux дополнительно потребуются права root (`sudo`) и системные пакеты (`portaudio19-dev python3-dev`).*
